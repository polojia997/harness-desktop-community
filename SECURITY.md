# Security Policy

Please do not publish suspected vulnerabilities in a public issue.

Until a private reporting address is configured, open a GitHub Security
Advisory in this repository.

Reports should include the affected version, reproduction steps, and expected
impact. Do not include real API keys or private workspace data.

Harness Desktop does not require or distribute a shared API key. Provider
credentials entered in Harness belong to the user and must never be committed
to this repository, attached to an issue, or included in diagnostic logs.

# Contributing

Thank you for helping improve Harness Desktop.

## Development

1. Install Node.js 24.
2. Run `npm.cmd install`.
3. Run `npm.cmd test`.
4. Run `npm.cmd start` for a local desktop build.

Keep desktop changes focused on Windows integration and upstream compatibility.
Do not copy upstream Harness source into this repository.

## Pull requests

- Explain the user-visible behavior.
- Include focused tests for runtime or security changes.
- Confirm that existing Harness profiles and sessions remain usable.
- Avoid committing API keys, personal profiles, build output, or logs.
